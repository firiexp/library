文体、見出し、箇条書き、MathJax の使い方をここに合わせる。

## 本文テンプレート

```md
## 説明
整数列から xor 基底を構築する。
基底の本数を $k$ とすると、表現できる値の個数は $2^k$。

## できること
$B$ を整数型 `T` のビット数とする。

- `XorBasis<T> lb`
  空の xor 基底を作る。$O(B)$
- `bool add(T x)`
  `x` を基底に追加する。独立なら `true`、追加されなければ `false`。$O(B)$
- `bool contains(T x)`
  `x` を基底で表せるなら `true`、表せなければ `false`。$O(B)$
- `T get_max(T x = 0)`
  基底で表せる `y` に対する `x xor y` の最大値を返す。空なら `x` を返す。$O(B)$

## 使い方
`XorBasis<unsigned long long> lb;` を作り、要素を `add` で順に入れる。
`T` には `bool` 以外の整数型を使う。値の大小は符号なし整数として比較する。
追加した値の集合を $S$ とすると、`get_max(x)` は
$$
\max_{y \in \langle S \rangle} (x \oplus y)
$$
を返す。$\langle S \rangle$ は、$S$ の要素を xor して作れる値全体を表す。
```

## 書き方の要点

- 先頭は `## 説明`、次に `## できること`、`## 使い方` を置く
- API 説明は短い箇条書きにする
- 失敗時や返り値の意味を 1 行で読めるように書く
- インライン数式は `$O(N \log N)$` のように書く
- 別行数式は次の形にする

```md
$$
f(i) = \sum_{j=0}^{i-1} a_j
$$
```

- バックスラッシュを含む集合記法や総和記号もそのまま MathJax で書く
- 例コードは利用手順や型定義が分かる最小限にする

### 計算量

- 計算量は「できること」の各 API 説明の末尾に添える。実装上の補足にまとめ直さない
- $N$ などの変数は使う前に意味を示す。最悪・償却・期待計算量の区別が必要なら明記する
- 定数倍や対数の定数の底は省く。64bit 単位の階層 bitset なら、操作の計算量は $O(\log N)$ と書く
- 通常の計算量表記に `max(2, N)` や `N + 1` のような境界値の補正を持ち込まない。空入力の振る舞いは必要に応じて文章で説明する
- 領域計算量は利用判断に役立つ場合に書く。直前の構造説明から明らかな内容や、定数倍を細かく残した式を重ねない
- 型や入力によって変わるパラメータは省かない。上のテンプレートでは、整数型のビット数を $B$ としている

例として、meld の説明は次の程度にする。$H$ の定義は API 一覧の前に置く。

```md
$H$ を全ヒープに含まれる要素数とする。

- `meld(a, b)`：`b` の要素を `a` に移し、`b` を空にする。$O(\log H)$
```

### 情報の置き場所

- 「説明」には何を扱うライブラリか、「できること」には API の動作と計算量、「使い方」には利用手順と型の指定を書く
- 利用に必要な前提条件や失敗時の返り値は、該当する API の説明に書く
- `n = 0` でも動くことなど、通常の利用で意識しない境界ケースを主な機能として列挙しない。伝える必要があれば「実装上の補足」に短く書く
- 「例」「実装上の補足」は必要な場合だけ足す。内部構造や実装の都合を、利用説明より詳しく書かない

### 型の説明と例

- 数値型を指定する API なら、`LeftistHeap<long long>` のように通常使う型を示す
- 利用者が群・モノイドなどを定義する API には、具体的な型と演算を持つ短い定義例を付ける。`using T = ...;` や関数宣言だけで済ませない
- 独自型の要件は、演算の意味が分かる形で書く。`T{}` が常に数値の0であるかのような説明をしない

例えば、加算を扱う独自型の要件は次のように書く。

> `T{}` で初期化した値が加算の単位元になるようにする。`T` が `long long` なら、この初期値は0になる。

群を指定する API なら、整数の加算を使う例は次のようになる。

```cpp
struct AddGroup {
    using T = long long;
    static T op(T a, T b) { return a + b; }
    static T inv(T a) { return -a; }
    static T e() { return 0; }
};

UndoableWeightedUnionFind<AddGroup> uf(3);
```

この例では値の型が `long long`、結合演算が加算、逆元が符号反転、単位元が0となる。
