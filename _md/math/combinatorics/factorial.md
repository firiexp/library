## 説明
階乗 `n!`、逆元 `n^{-1}`、階乗逆元 `(n!)^{-1}` を必要になったところまで遅延計算する。
二項係数、順列数、重複組合せを求める。


## できること
表の拡張が不要な参照は $O(1)$。拡張が必要な場合は、以下の時間に `ensure` の計算量が加わる。
$\Delta$ を追加する要素数、$M$ を `Mint` の法とする。

- `Factorial<Mint = mint> f(int n = 0)`
  `0` から `n` まで前計算して作る。$O(n+\log M)$
- `void ensure(int n)`
  `n` まで前計算を広げる。拡張時は償却 $O(\Delta+\log M)$
- `int max_n()`
  現在前計算済みの最大添字を返す。$O(1)$
- `Mint fact(int k)`
  `k >= 0` なら `k!`、`k < 0` なら `(-k)!^{-1}` を返す。$O(1)$
- `Mint inv(int k)`
  `k^{-1}` を返す。`k < 0` なら `0`。$O(1)$
- `Mint inv_fact(int k)`
  `(k!)^{-1}` を返す。`k < 0` なら `0`。$O(1)$
- `Mint operator[](int k)`
  `k >= 0` なら `k!`、`k < 0` なら `(-k)!^{-1}` を返す。$O(1)$
- `Mint C(int n, int k)`
  二項係数を返す。`n < 0`、`k < 0`、`k > n` なら `0`。$O(1)$
- `Mint large_C(long long n, long long k)`
  $t=\min(k,n-k)$ が小さいときの二項係数 $\binom{n}{k}$ を返す。`n < 0`、`k < 0`、`k > n` なら `0`。$O(t)$
- `Mint P(int n, int k)`
  順列数を返す。`n < 0`、`k < 0`、`k > n` なら `0`。$O(1)$
- `Mint H(int n, int k)`
  重複組合せ $\binom{n+k-1}{k}$ を返す。負の引数では `0`。`k = 0` なら `1`、`n = 0` かつ `k > 0` なら `0`。$O(1)$

## 使い方
`Factorial<Mint> f(n);` で必要な範囲を用意する。同じ `Mint` のインスタンスは静的な表を共有し、`ensure` は指定された上限までだけ広げる。
逆元・階乗逆元と `C/P/H/large_C` は固定の素数 mod を前提とする。`C/P` で使う階乗の添字 `n` と、`H` で使う添字 `n+k-1` は法未満とする。

`large_C` は $t<mod$ を前提とし、`n >= mod` でも使える。表は `t` までだけ拡張し、前計算を含めて時間・領域は $O(t)$。

```cpp
Factorial<modint<1000000007>> f;
auto a = f.large_C(1000000000000000000LL, 3);
auto b = f.large_C(1000000000000000000LL, 999999999999999997LL);
assert(a == b);
```

## 実装上の補足
`large_C` は短い分子の積と `inv_fact(t)` を掛ける。`t<mod` なので分母は可逆で、`n % mod < t` なら分子に mod の倍数が含まれるため表を拡張せず `0` を返す。

増分 $\Delta$ が500万以上で、法が素数かつ新しい上限が法未満なら、末尾の階乗逆元を1回求めて逆走査する。それ以外は整数除算を使う漸化式で広げる。既存の表は書き換えず、法をまたいでも法未満の階乗逆元を保持する。
素数判定は逆走査が初めて候補になるときに行い、`Mint` ごとに結果を保持する。逆走査の拡張は償却 $O(\Delta+\log M)$、通常の拡張は償却 $O(\Delta)$、前計算済みの参照は $O(1)$。最大の前計算添字を $N$ とすると、3本の表の領域は $O(N)$。
