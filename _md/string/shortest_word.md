## 説明
`DFA<W>` が受理する最短の文字列を復元する。同じ長さの解が複数ある場合は、指定した文字の順序で辞書順最小のものを返す。

## できること

- `optional<string> shortest_word(a, alphabet)` : 最短の受理文字列を返す。解なしは `nullopt`。空文字列を受理する場合は空文字列を返す

`alphabet` は文字番号 `0..W-1` に対応する長さ $W$ の文字列。例えば `"ab"` なら番号0を `'a'`、番号1を `'b'` として返す。
辞書順は `alphabet` に並べた順とする。

状態数を $S$、文字種数を $W$ として、時間 $O(SW)$、追加領域 $O(S)$。

## 使い方
`string/avoid_patterns.cpp` と併用し、禁止語の条件を長さの条件と合成できる。

```cpp
auto avoid = avoid_patterns<2, 'a'>({"a"});
DFA<2> odd{ { {1, 1}, {0, 0}}, {false, true}, 0};
auto word = shortest_word(intersect(avoid, odd), "ab");
```

この例は `"a"` を含まない奇数長の文字列を求め、`"b"` を返す。
`avoid` 単独を渡すと空文字列を返す。手書きの遷移表や他の積 DFA も渡せる。

## 実装上の補足
初期状態から文字順に幅優先探索し、各状態に初めて到達したときの親と文字を保持する。
各状態を1回だけ探索するため、閉路があっても停止する。解があれば長さは $S-1$ 以下。
`initial == -1` は全拒否、遷移先 `-1` は拒否遷移として扱う。
数字を返す場合は `"0123456789"` を渡す。数値としての先頭0制約は DFA 側で表す。
