## 説明

固定した配列の区間ごとに、最も多く現れる値とその出現回数を求める。クエリは1件ずつ処理できる。

## できること

配列の長さを $N$ とし、要素の比較とコピーは定数時間とする。

- `StaticRangeMode<T> mode(a)`
  配列 `a` から構築する。`T` は `<` で比較できる型とする。構築時間は $O(N\sqrt{N})$、領域は $O(N)$。
- `pair<T, int> query(int l, int r) const`
  半開区間 `[l, r)` の最頻値とその出現回数を返す。最頻値が複数あれば、そのうちの1つを返す。$0 \le l < r \le N$ を満たす必要がある。時間は $O(\sqrt{N})$。

## 使い方

```cpp
StaticRangeMode<int> mode({4, 7, 4, 7, 7});
auto [value, freq] = mode.query(1, 5);  // value == 7, freq == 3
```

## 実装上の補足

各ブロックの先頭から右へ走査し、ブロック末尾に達するたびに最頻値と出現回数を表に記録する。ブロック数は $O(\sqrt{N})$ なので、走査には合計 $O(N\sqrt{N})$ 時間かかり、表の大きさは $O(N)$ になる。

クエリでは区間に丸ごと入るブロック列の最頻値を表から取り出す。残った左端の要素は左から、右端の要素は右から調べる。丸ごと入るブロックがなければ、初期頻度を $0$ として区間全体を左から調べる。

値ごとに出現位置を昇順に並べ、配列の各位置がそのリストの何番目かも記録しておく。現在の最大頻度を $f$ とすると、左からの走査でリストの $f$ 個先の位置が区間内にあれば、最大頻度を $1$ 増やせる。右からの走査では $f$ 個前を調べる。各判定は定数時間で済み、最大頻度の増加分は端に残った要素数以下なので、クエリ全体で $O(\sqrt{N})$ 時間となる。
