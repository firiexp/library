## 説明
単純無向グラフの長さ4の閉路（$C_4$）の個数を求める。向かい合う頂点を結ぶ弦がある閉路も数える。

## できること
頂点数を $N$、辺数を $M$ とする。

- `long long count_c4(int n, const vector<pair<int, int>> &edges)`
  長さ4の閉路の総数を返す。時間 $O(N+M\sqrt{M})$、領域 $O(N+M)$

## 使い方
頂点番号は $0$ から $N-1$ とし、各無向辺を1回ずつ渡す。自己ループと多重辺は含めない。

```cpp
vector<pair<int, int>> edges{
    {0, 1}, {1, 2}, {2, 3}, {3, 0}, {0, 2}, {1, 3}
};
long long cycles = count_c4(4, edges);  // 3
```

## 実装上の補足
次数（同次数なら頂点番号）で頂点に順序を付け、閉路で最大の頂点を始点としてそれより小さい頂点だけを通る長さ2の道を数える。終点が一致する2本の道から閉路がちょうど1つ定まる。
