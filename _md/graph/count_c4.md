## 説明
単純無向グラフで、異なる4頂点を通る長さ4の閉路を数える。始点や巡回方向が違うだけの閉路は1個と数える。向かい合う頂点を結ぶ辺（弦）がある閉路も数える。

## できること
- `long long count_c4(int n, const vector<pair<int, int>>& edges)` は閉路の総数を返す。頂点数を $N$、辺数を $M$ とすると、時間 $O(N+M\sqrt M)$、作業領域 $O(N+M)$。

## 使い方
頂点番号は $0$ から $N-1$ とし、各無向辺を1回ずつ渡す。自己ループと多重辺は使えない。辺数は `int` の範囲とする。

```cpp
vector<pair<int, int>> edges{
    {0, 1}, {1, 2}, {2, 3}, {3, 0}, {0, 2}, {1, 3}
};
long long cycles = count_c4(4, edges);  // 3
```

## 実装上の補足
頂点の大小は次数で決め、同じ次数なら頂点番号を比べる。閉路で最大の頂点を始点とし、それより小さい頂点だけを通る長さ2の道をたどる。終点が同じ道を2本選ぶと、ちょうど1個の閉路ができる。

各閉路には向かい合う辺の組が2つあり、同じ辺の組が向かい合う閉路は高々2個である。したがって閉路数は $M(M-1)/2$ 以下で、32ビットの `int` で表せる辺数なら答えは `long long` に収まる。
