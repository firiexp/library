## 説明

無向グラフの隣り合う頂点が異なる色になるように、すべての頂点を塗るための最小の色数を求める。

## できること

- `int chromatic_number(int n, const vector<pair<int, int>> &edges)`
  $0 \le n \le 20$ の単純無向グラフの彩色数を返す。頂点番号は $0$ から $n-1$ で、`edges` には各辺の両端を1組ずつ渡す。
  頂点がなければ $0$、頂点があって辺がなければ $1$ を返す。時間 $O(n2^n)$、作業領域 $O(2^n)$。

## 使い方

```cpp
vector<pair<int, int>> edges = { {0, 1}, {1, 2}, {2, 3}, {3, 4}, {4, 0} };
int colors = chromatic_number(5, edges);  // 3
```

## 実装上の補足

頂点部分集合 $S$ に含まれる独立集合の個数を $I(S)$ とする。空集合も1個と数える。
この個数は独立集合の指示関数の部分集合ゼータ変換にあたる。$S$ の1頂点を使う場合と使わない場合に分けて、すべての $I(S)$ を $O(2^n)$ 時間で求める。
包除原理により、順序付きの $k$ 個の独立集合で全頂点を覆う方法の数は $\sum_S (-1)^{n-|S|} I(S)^k$ となる。
被覆があれば、各頂点についてその頂点を含む集合を1個選び、集合の番号を色にできる。逆に、$k$ 色以下で塗れれば各色の頂点集合が被覆になる。

各頂点が所属する集合の選び方は高々 $2^k$ 通りなので、被覆数は $2^{nk}$ 以下である。$n$ 色あれば必ず塗れるため、判定するのは $k<n$ の範囲で、$nk \le 380$ となる。
異なる11個の素数をそれぞれ $2^{35}$ 以上になるまで累乗し、その値を mod として被覆数を計算する。
これらは互いに素で積が $2^{385}$ 以上になるため、すべての剰余が $0$ なら被覆数も $0$ と確定する。
